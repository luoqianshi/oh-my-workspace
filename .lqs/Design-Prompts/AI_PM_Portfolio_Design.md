# AI PM 个人作品集网站设计文档

## 项目概述

**产品名称**: 骆某 AI PM Portfolio  
**设计风格**: Neumorphism (Soft UI)  
**技术栈**: Astro + Tailwind CSS + React  
**部署目标**: GitHub Pages / Netlify

---

## 核心设计理念

### 千人千面的身份系统
用户进入网站时可选择身份视角，整个网站的内容排序、推荐和文案会根据身份动态调整。

**三个身份角色:**
1. **研究生小骆** (紫罗兰 `#6C63FF`) - 学术/研究视角
2. **工程师骆总** (青色 `#38B2AC`) - 技术/工程视角
3. **辅导员骆导** (琥珀橙 `#F59E0B`) - 教育/指导视角

---

## 视觉系统

### 色彩体系

**基础色:**
- 主背景: `#E0E5EC` (冷灰色，贯穿全站)
- 主文字: `#3D4852` (深蓝灰，7.5:1对比度)
- 次要文字: `#6B7280` (中灰，4.6:1对比度)

**角色标识色:**
- 研究生小骆: `#6C63FF` (紫罗兰)
- 工程师骆总: `#38B2AC` (青色)
- 辅导员骆导: `#F59E0B` (琥珀橙)

**强调色:**
- 主强调: `#6C63FF` (紫罗兰)
- 成功/正面: `#38B2AC` (青色)

### Neumorphism 阴影系统

**浮起状态 (默认卡片):**
```css
box-shadow: 9px 9px 16px rgb(163,177,198,0.6), 
            -9px -9px 16px rgba(255,255,255,0.5);
```

**悬停状态:**
```css
box-shadow: 12px 12px 20px rgb(163,177,198,0.7), 
            -12px -12px 20px rgba(255,255,255,0.6);
transform: translateY(-2px);
```

**按下状态 (按钮):**
```css
box-shadow: inset 6px 6px 10px rgb(163,177,198,0.6), 
            inset -6px -6px 10px rgba(255,255,255,0.5);
```

**深井状态 (输入框、图标槽):**
```css
box-shadow: inset 10px 10px 20px rgb(163,177,198,0.7), 
            inset -10px -10px 20px rgba(255,255,255,0.6);
```

### 字体系统

- **标题字体**: Plus Jakarta Sans (500, 600, 700, 800)
- **正文字体**: DM Sans (400, 500, 700)
- **代码字体**: JetBrains Mono / monospace

### 圆角规范

- 大容器/卡片: `32px` (`rounded-[32px]`)
- 按钮/输入框: `16px` (`rounded-2xl`)
- 内部元素: `12px` (`rounded-xl`) 或 `9999px` (`rounded-full`)

## 页面结构

单页滚动布局，包含以下区块:

1. **固定顶部导航栏**
2. **Hero 区域** (身份切换器 + 个人介绍)
3. **作品广场** (项目网格展示)
4. **AI 工具箱** (工具卡片 + Prompt集合)
5. **AI 资源库** (学习资源列表)
6. **联系我** (联系方式卡片)
7. **页脚**

---

## 区块详细设计

### 1. 固定顶部导航栏

**布局:**
- 固定顶部, `z-index: 50`
- 高度 `72px`, 内部容器 `max-w-7xl` 居中
- 背景: `backdrop-blur-md` 毛玻璃 + `rgba(224,229,236,0.8)`

**内容:**
- 左侧: Logo/姓名 "骆某"
- 中部: 导航链接 (首页、作品、工具箱、资源库、联系)
- 右侧: 当前身份显示 + 切换按钮

**身份切换按钮:**
- 圆角 `rounded-full`
- 内凹设计 + 当前角色色边框
- 点击展开下拉菜单

---

### 2. Hero 区域

**布局:**

- 背景: `#E0E5EC` + 装饰性同心圆

**内容层级:**

#### 2.2 个人介绍 (动态切换)
- 定位标签 (角色色):
  - 研究生: "AI 研究方向 | 深度学习 × 产品思维"
  - 工程师: "全栈开发者 | 技术架构 × 工程实践"
  - 辅导员: "教育引导者 | 知识传播 × 成长陪伴"
- 姓名: "骆某" (`text-7xl md:text-8xl`, `font-extrabold`)
- 2-3句自我介绍 (根据身份动态)

#### 2.3 CTA 按钮组
- 主按钮: "查看作品" (角色色背景)
- 次按钮: "下载简历" (浮起效果)

#### 2.4 社交链接

## 交互规范

### 动画时长
- UI 元素: `300ms`
- 页面滚动: 平滑滚动 `scroll-behavior: smooth`
- 缓动函数: `ease-out`

### 悬停效果
- 卡片: `-translate-y-1` + 阴影增强
- 按钮: `-translate-y-1` (悬停) / `translate-y-0.5` (按下)
- 图标: 轻微放大

### 身份切换
- 选择身份后, 全站内容实时更新
- 过渡动画: 内容淡出 → 更新 → 淡入 (300ms)
- 角色色贯穿始终

## 技术实现要点

1. **状态管理**: 使用 React Context 或 Nano Stores 管理全局身份状态
2. **内容切换**: 根据当前身份过滤和排序内容
3. **动画**: CSS transitions + Framer Motion (复杂交互)
4. **图标**: Lucide React
5. **字体**: Google Fonts (Plus Jakarta Sans + DM Sans)
